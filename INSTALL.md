# Get the LGO RV Park Deal Screener

One-time setup. Takes about 2 minutes. You only do this once.

1. **Open the Claude app on your computer.** It must be the desktop app — not the website, not your phone. Don't have it? Download it free at [claude.ai/download](https://claude.ai/download) and sign in.
2. **Click “Cowork”** in the left side menu.
3. **Click “Customize”** (also in the left side menu), then click the **“Plugins”** tab.
4. Find the **“Personal plugins”** section. Click the **+** (plus) button, then click **“Add marketplace.”**
5. Choose **“Add from a repository.”** Type this in the box exactly (or copy-paste it):

   ```
   SherpaOS/lgo-tools-marketplace
   ```

6. You'll see a plugin called **lgo-rv-underwrite**. Click **“Install.”** That's it — you're done.
7. **Try it out:** start a new Cowork task, paste in an RV park listing (or your notes from a seller call), and ask: *“worth chasing?”* Claude will run the numbers and hand you a one-page LGO Deal Snapshot with a verdict.

## Stuck? Check these 3 things first

- **Can't find “Customize”?** Make sure you clicked “Cowork” first, and that you're in the desktop app — this doesn't work on the website or phone.
- **Nothing shows up after adding the marketplace?** The repository name was probably typed wrong. Delete it and copy-paste it exactly: `SherpaOS/lgo-tools-marketplace`
- **No “Plugins” tab?** Update your Claude desktop app to the latest version, then try again.
